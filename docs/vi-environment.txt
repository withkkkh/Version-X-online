VI 背景本地试版 · 动态与清晰度

A 当前实现：vi-directional-background.js 用 WebGL2 全屏三角形实时计算环境，每个屏幕像素按相机朝向、俯仰和视野生成世界空间射线。冰蓝银灰光场、圆角点阵都是函数生成，颗粒为细微像素噪声；点阵用导数抗锯齿。没有低分辨率全景纹理的局部放大，因此既能保持边缘清晰，也能随相机旋转变化。

渲染随 camera-change、load 和 ResizeObserver 更新，静止时不持续重绘。屏幕像素比最高2，兼顾移动设备性能。WebGL2 不可用或编译失败时退回 vi-graphic-background.js 的静态高分辨率 Canvas 版本。A 不再请求先前的全景图片。

B 当前实现：用户提供的空间 PNG 作为完整二维构图背景，保留窗墙。该选项用于比较艺术方向。左上角“背景对比”即时切换，URL background=vi 或 background=studio 保留选择。

模型、HDRI 中性光照、相机及导览路线保留。切换 A/B 时先暂停导览并维持当前相机。封面先进入完整策展导言，再选择自动导览或自由参观。设计团队页已删除“发散与收敛”说明框。

验证：本机 WebGL2 版本实际渲染；通过键盘旋转相机，环境 yaw/pitch 与重绘次数同步改变。导览切换正常；390px手机布局无横向溢出，背景按新视口重新分配像素；浏览器无错误。保留本地预览，未发布 GitHub Pages。

色彩增强：扩大世界空间光场的银白/冰蓝/钴蓝明度和色调差异；加入银色条形高光。点阵会根据环境明暗切换深浅，深蓝方向也能看见纹理。变化由观察方向决定，不使用定时随机变色。已实测默认角度与转动约90°的背景颜色明显不同，浏览器无错误；仍为本地预览。

已移除动态着色器和静态备用渲染中的矩形玻璃面板及白色描边，保留连续光带、视角联动色彩与点阵。浏览器已验证旋转后的效果。
