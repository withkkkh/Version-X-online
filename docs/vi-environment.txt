按用户提供的冰蓝点阵海报、银色液态 X、玻璃立面与颗粒蓝海报制作。弃用此前的写实灰色房间背景。

可见背景：gallery-vi-skybox.jpg，2:1 全景贴图，由 imagegen 参考 VI 生成，JPEG 编码约174KB。使用 model-viewer 的 skybox-image 接入，随相机方向变化；不是纯色平铺。

照明：gallery-neutral-studio.hdr，由 tools/build-gallery-lighting.mjs 生成。单独的中性柔光环境避免可见背景把展墙染蓝，保留灰色地面、白色墙面和接触阴影。新增贴图和照明合计约207KB。environment.css 统一背景边缘、页眉和文字颜色。

内容：删除设计团队页的“发散与收敛”说明框，保留同理心、批判性、想象力、感知力及项目索引。

验证：浏览器查看总览、团队近景与横向切换、390px手机端和设计团队页；无控制台错误。仅本地预览，未推送到 GitHub Pages。

A/B 本地背景对比：左上角“背景对比”可即时切换，URL background=vi 或 background=studio 保留选择。切换不改相机、模型或 HDRI 光照；播放导览时先暂停，保持当前视角。封面与策展导言流程保留。

A 使用生成时的原始 PNG，避免 JPEG 再压缩。原图自带柔光且宽度有限；全景只取小视角区域铺满屏幕，会继续放大柔化与采样限制，原始 PNG 并不能恢复不存在的细节。

B 使用用户这次上传的原始空间 PNG 作为完整二维构图背景，保留窗墙结构；不把它重新包成全景。原因是俯视镜头下全景映射主要只看见地面，且原图并非经过严格校准的 HDRI。本版用于比较视觉方向，尚未发布。

验证：A/B 切换、URL 初始化、近景下切换会暂停导览且相机不变、390px 控件布局无横向溢出。浏览器无错误。
